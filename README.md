# samp-scripts

Каталог скриптов MoonLoader для GTA San Andreas (SA-MP) от автора SNHelper: готовые сборки скриптов, их картинки и общие библиотеки, которые эти скрипты докачивают сами.

Из этого репозитория читают:

- **SNHelper**, раздел «Другие скрипты» - список `scripts.json`, картинки и файлы для кнопок «Установить», «Обновить», «Удалить»;
- загрузчики скриптов (SNHelper, Аудиоплеер) - недостающие библиотеки из `deps/`.

Скрипты в каталоге - только скрипты автора.

## Раскладка

```
scripts.json                 список скриптов каталога
deps/                        общие библиотеки и ресурсы; путь внутри deps/ = путь внутри папки moonloader игры
  lib/imgui.lua, lib/MoonImGui.dll, ...
  resource/fonts/fa-solid-900.ttf
  resource/SNHelper/fastest_words.txt   (словарь «Анаграммы» SNHelper, необязательный)
scripts/<id>/                готовые сборки скрипта (то, что кладётся в moonloader)
images/<id>.png              картинка карточки скрипта
tools/update_sizes.lua       пересчёт размеров в scripts.json
```

Файлы в `deps/` и `scripts/` хранятся ровно в том виде, в каком их читает игра: сборки скриптов - в CP1251, библиотеки - как есть.

## scripts.json

```json
{
  "format": 1,
  "scripts": [
    {
      "id": "audio-player",
      "name": "Аудиоплеер",
      "description": "Радиостанции и музыка из папки...",
      "version": "1.0",
      "version_num": 1,
      "image": "images/audio-player.png",
      "main": "samp-audio-player.lua",
      "files": [
        { "path": "samp-audio-player.lua", "size": 46157, "src": "scripts/audio-player/samp-audio-player.lua" }
      ],
      "deps": [
        { "path": "lib/imgui.lua", "size": 114068, "src": "deps/lib/imgui.lua" }
      ]
    }
  ]
}
```

| Поле | Что это |
|---|---|
| `format` | версия формата, сейчас `1`. Другой номер SNHelper не читает и показывает ошибку |
| `id` | латиница в нижнем регистре, цифры, `-`, `_`, до 40 символов. Уникален. От него зависят имя картинки в игре и запись в файле состояния |
| `name`, `description` | название и описание для карточки (описание переносится по ширине) |
| `version` | версия для показа («1.0») |
| `version_num` | целое число. Если в каталоге оно больше установленного, на карточке появляется «Обновить». **Поднимайте при каждом выпуске** |
| `image` | необязательно: PNG в репозитории. Игра скачивает его один раз в `moonloader/resource/SNHelper/catalog/<id>.png`; не PNG или нет файла - на карточке заглушка |
| `main` | главный файл скрипта в корне папки `moonloader` (`.lua` или `.luac`). По нему SNHelper понимает, что скрипт установлен, и его запускает или выгружает. Должен быть в `files` |
| `files` | свои файлы скрипта: `path` - куда в папке `moonloader`, `size` - размер в байтах, `src` - откуда в этом репозитории. Скачиваются при установке и обновлении все; при удалении удаляются |
| `deps` | общие файлы из `deps/`, той же формы. Скачиваются, только если их нет или размер другой; при удалении скрипта не удаляются |

Запись с ошибкой SNHelper пропускает (остальные показывает) и пишет, сколько записей пропущено.

### Правила путей

SNHelper принимает только пути внутри папки `moonloader`: латиница, цифры, `-`, `_`, `.` и `/` между папками. Нельзя: `..`, `.`, пустые части (`a//b`), ведущий `/`, обратную косую, двоеточие (`C:`), точку в конце имени, имена устройств Windows (`con`, `nul`, `com1`...). Через `files` нельзя заменить сам SNHelper и его библиотеки; через `deps` - сам SNHelper, а общие файлы, которые есть у SNHelper, только докачиваются, если их нет, и никогда не перезаписываются. Адрес репозитория в SNHelper зашит, другие адреса он не берёт.

### Кодировка текстов

`scripts.json` хранится в **UTF-8 без BOM**; русские буквы пишите как есть, без `а`-кодов. Встроенный в MoonLoader `decodeJson` возвращает строки в том виде, в каком они лежат в файле, то есть в UTF-8. Перевод делает скрипт, который читает каталог (SNHelper):

- в окне ImGui тексты каталога выводятся как есть - ImGui ждёт UTF-8;
- в чат и во всплывающие уведомления (они в CP1251, как чат игры) тексты идут через `u8:decode(...)`.

## Как выпустить скрипт или обновление

1. Соберите скрипт и положите сборку в `scripts/<id>/` (для Аудиоплеера: `tools/build.sh --publish <путь к samp-scripts>` в его исходниках).
2. В записи скрипта поднимите `version` и `version_num`; новые файлы добавьте в `files` или `deps` (каждый файл - **одной строкой**, как в примере).
3. Пересчитайте размеры и проверьте, что все файлы на месте:

   ```bash
   luajit tools/update_sizes.lua
   luajit tools/update_sizes.lua --check
   ```

4. Закоммитьте и отправьте. Игроки увидят «Обновить» после «Обновить список» в SNHelper или при следующем открытии раздела.

Размеры нужны для проверки скачанного файла: если размер не совпал (обрыв связи, страница ошибки), файл не заменяется. Поэтому после любой правки файла запускайте `update_sizes.lua`.

## deps/

Общие библиотеки для загрузчиков скриптов. Загрузчик скачивает файл, только если его нет (или он пустой, или модуль не подключается), и сверяет размер с размером в своём списке. Поэтому:

- файлы в `deps/` должны совпадать по размеру со списками в скриптах (SNHelper - `SNBoot.DEPS`, Аудиоплеер - `APBoot.DEPS`); при обновлении библиотеки обновите и списки, и `scripts.json`;
- дерево `deps/` для SNHelper собирает его инструмент выпуска (папка `dist/samp-scripts/deps`), его копируют сюда целиком;
- удалять файлы из `deps/` нельзя, пока их ждут уже установленные у игроков версии скриптов.
